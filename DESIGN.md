# Index design

Persuade surface with a user-pinned composition: 48:52 text/image hero, immediate download, then capabilities, guide and dark download panel. Noto Sans Thai, #F8FAFC ground, #0F172A headings, #475569 text, #2563EB primary, #1D4ED8 hover and #E2E8F0 borders.

Only installer buttons use a periodic light sweep, inset highlight and lifted hover. Reduced motion disables motion. The screenshot placeholder has blue light and a perspective grid; no fabricated product UI. Capabilities use open columns and the guide uses a divided horizontal composition. Mobile uses text, download, then image. Disabled guide links remain focusable with aria-disabled and an associated status.
