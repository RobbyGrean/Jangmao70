ดาวน์โหลดไฟล์

ดาวน์โหลดตัวติดตั้งดาวน์โหลด Source code

ตรวจชื่อไฟล์ก่อนเปิดทุกครั้ง ต้องเป็นไฟล์จาก repository RobbyGrean/Jangmao70 และชื่อควรตรงกับไฟล์ด้านบน

คำเตือนจาก Chrome
Chrome อาจเตือนว่าไฟล์ ZIP ดูน่าสงสัย เพราะไฟล์ยังมีผู้ดาวน์โหลดไม่มากหรือยังไม่มีชื่อเสียงจากผู้ให้บริการ คำเตือนอาจเกิดกับทั้ง Installer และ Source ZIP
  1. เปิดรายการดาวน์โหลดของ Chrome แล้วคลิกรายการที่มีคำเตือนหรือเครื่องหมายลูกศร
  2. ตรวจว่าดาวน์โหลดจาก RobbyGrean/Jangmao70 และชื่อไฟล์เป็น Jangmao70-Installer.zip
  3. เมื่อตรวจสอบและเชื่อถือไฟล์แล้ว คลิก ดาวน์โหลดไฟล์ที่น่าสงสัย (บางรุ่นใช้ Keep / เก็บไว้ หรือ Keep anyway / เก็บไว้ต่อไป)
  4. ดาวน์โหลดเสร็จแล้ว แตก ZIP ก่อนเปิด Jangmao70-Setup.exe

ภาพเป็นตัวอย่างจาก jmoney รุ่นก่อน หน้าตาอาจเปลี่ยนตามรุ่น Chrome แต่หลักการตรวจสอบเหมือนกัน

  1. ดาวน์โหลดจาก repository RobbyGrean/Jangmao70 จริง
  2. ชื่อไฟล์ตรงกับ Jangmao70-Installer.zip หรือ Jangmao70-Source.zip
  3. ถ้าแหล่งที่มาหรือชื่อไฟล์ไม่ตรง ให้ยกเลิกและอย่าเปิดไฟล์

วิธีติดตั้ง

  1. ดาวน์โหลด Jangmao70-Installer.zip
  2. คลิกขวาไฟล์ ZIP แล้วเลือก Extract All / แตกไฟล์ทั้งหมด
  3. เปิดโฟลเดอร์ที่แตกออกมา แล้วเปิด Jangmao70-Setup.exe
  4. รอให้ตัวติดตั้งทำงานจนเสร็จ
  5. เปิดโปรแกรมจาก shortcut ชื่อ Jangmao70 บน Desktop หรือ Start Menu
ก่อนติดตั้งรุ่นใหม่
อย่าเปิด Setup จากด้านใน ZIP และควรปิด Jangmao70 กับไฟล์ Word ที่เกี่ยวข้องก่อนติดตั้งรุ่นใหม่ทับรุ่นเดิม

เมื่อขึ้น Windows protected your PC

More info → Run anyway

  1. เมื่อขึ้น Windows protected your PC ให้คลิก More info / ข้อมูลเพิ่มเติม ตามวงกลมในภาพ
  2. ตรวจชื่อแอปให้เป็น Jangmao70-Setup.exe จากไฟล์ที่ดาวน์โหลดจากเว็บไซต์นี้
  3. คลิก Run anyway / เรียกใช้ต่อไป ที่ปรากฏขึ้น แล้วทำตามหน้าต่างติดตั้ง

SmartScreen อาจเตือนเมื่อแอปยังไม่มีชื่อเสียงเพียงพอหรือไม่มีลายเซ็นที่ระบบรู้จัก ให้ทำต่อเฉพาะไฟล์ที่คุณตรวจสอบและเชื่อถือ หากไม่มีปุ่ม Run anyway เครื่องอาจถูกควบคุมด้วยนโยบายองค์กร ให้ติดต่อผู้ดูแลเครื่อง

เริ่มใช้งาน

Jangmao70 เป็นโปรแกรม Windows แบบออฟไลน์ มีสองแท็บ: สีเขียวสำหรับจัดซื้อจัดจ้างและสัญญา สีฟ้าสำหรับเบิกเงินเดือน แต่ละแท็บแยกข้อมูลเฉพาะงานและสร้างผลลัพธ์คนละโฟลเดอร์

ดูภาพหน้าจอจริงของทั้งสองแท็บที่หน้าแรก

แท็บจัดซื้อจัดจ้างและสัญญา

  1. ข้อมูลโรงเรียน — ชื่อโรงเรียน เขตพื้นที่ และผู้รับผิดชอบ
  2. กรรมการ TOR — กรรมการ 1–3 และเลขที่คำสั่งแต่งตั้ง TOR และตรวจรับ
  3. ข้อมูลลูกจ้าง — ข้อมูลส่วนตัว ตำแหน่ง เงินเดือน การศึกษา ที่อยู่ และข้อมูลบัตร
  4. สรุปชุดเอกสารที่ต้องการสร้าง — ตรวจรายการเอกสารก่อนสร้าง

แท็บเบิกเงินเดือน

กรอกข้อมูลรอบเบิก ผู้รับจ้าง ตำแหน่ง เงินเดือน วันที่ และข้อมูลผู้ลงนาม จากนั้นเลือกเอกสารที่ต้องการสร้าง

ถ้าใช้คำสั่ง เหมือนเดิม! แค่เปลี่ยนเดือน! ระบบจะเสนอเดือนถัดไปจากประวัติการสร้างเอกสารสำเร็จล่าสุดของ Template นั้น ผู้ใช้ต้องยืนยันก่อนเลื่อนเดือน หาก Template ยังไม่มีประวัติสร้างสำเร็จ ระบบจะโหลดข้อมูลแต่ให้เลือกเดือนเอง ตรวจเดือน ปี และวันที่ส่งเบิกทุกครั้งก่อนสร้าง

ช่องที่มีเครื่องหมาย * เป็นข้อมูลที่ควรกรอกเพื่อให้เอกสารสมบูรณ์ ช่องที่เว้นว่างอาจถูกแทนด้วยจุดตามที่ระบบกำหนด

โหลดและบันทึก Template

  • บันทึก Template คือเก็บข้อมูลที่กรอกไว้ใช้ครั้งต่อไป ไม่ใช่การแก้ไฟล์ Word ต้นฉบับ
  • โหลด Template คือนำข้อมูลที่เคยบันทึกกลับมาใส่ในฟอร์ม
  • การโหลดข้ามแท็บจะเปิดหน้าต่างให้เลือกว่าจะนำเข้าจากชุดจัดซื้อจัดจ้างและสัญญา หรือจากข้อมูลเบิกเงินเดือนเดิม
  • ก่อนยืนยันนำเข้าข้ามงาน ระบบจะแจ้งข้อมูลร่วมที่จะเขียนทับ ข้อมูลเฉพาะงานที่ไม่นำเข้า ช่องที่ต้นทางว่างซึ่งจะเขียนทับปลายทางเป็นค่าว่าง และช่องที่ไม่มีในต้นทางซึ่งจะคงค่าปลายทางเดิม

ข้อมูลที่ใช้ร่วมกันได้ เช่น ชื่อโรงเรียน/เขต ผู้อำนวยการ เจ้าหน้าที่พัสดุ หัวหน้าเจ้าหน้าที่พัสดุ และข้อมูลลูกจ้าง เช่น ชื่อ เลขประชาชนและที่อยู่ จะถูกนำเข้าตามรายการที่ระบบรองรับ ส่วนงวดเบิก รายการเอกสาร กรรมการ TOR/ตรวจรับ ตำแหน่ง เงินเดือน และข้อมูลเฉพาะของแต่ละแท็บยังคงแยกกัน

ข้อมูล Template และค่าที่บันทึกไว้เป็นข้อมูลภายในเครื่อง เก็บไว้ในเครื่อง ควรสำรองข้อมูลก่อนย้ายเครื่องหรือติดตั้งระบบใหม่

สร้างเอกสาร

  1. ตรวจข้อมูลทุก section ให้ครบ
  2. ตรวจรายการเอกสารที่เลือก
  3. กด ตรวจสอบและสร้างเอกสาร หรือ ตรวจสอบและสร้าง Word
  4. รอจนระบบแจ้งผลสำเร็จ แล้วเปิดโฟลเดอร์ Output ตรวจไฟล์ Word

โฟลเดอร์ผลลัพธ์เริ่มต้นอยู่ที่:

%LOCALAPPDATA%\Jangmao70\Output\เอกสารจัดจ้าง %LOCALAPPDATA%\Jangmao70\Output\เงินเดือน

ชื่อไฟล์ผลลัพธ์อิงชื่อผู้รับจ้าง ชื่อ Template และวันที่สร้างเอกสาร หากสร้างซ้ำในวันเดียวกัน ให้ตรวจชื่อไฟล์และไฟล์เดิมก่อนนำไปใช้งาน เพื่อป้องกันการใช้เอกสารผิดชุด

การปิดโปรแกรม

ถ้ามีข้อมูลที่ยังไม่ได้บันทึกก่อนปิด โปรแกรมจะถามว่าจะบันทึกหรือไม่ ให้เลือกตามต้องการ หากยกเลิกหรือปิดกล่องคำถาม ข้อมูลในฟอร์มจะยังไม่ถูกทิ้ง

ปัญหาที่พบบ่อย

อาการวิธีตรวจสอบเบื้องต้น
ดาวน์โหลดแล้ว Chrome เตือนตรวจ repository และชื่อไฟล์ก่อนเลือกดาวน์โหลดต่อ
Windows ขึ้น SmartScreenตรวจแหล่งที่มาและชื่อไฟล์ ห้ามปิดระบบป้องกันทั้งเครื่อง
เปิด Setup ไม่ได้แตก ZIP ก่อน และตรวจว่ามี Jangmao70-Setup.exe อยู่ในโฟลเดอร์ที่แตกแล้ว
สร้างเอกสารไม่ครบตรวจช่องที่มี * รายการเอกสาร และ Template ที่เลือก
Word เปิดไฟล์ไม่ได้ปิดเอกสาร Word ที่ชื่อเดียวกัน แล้วลองสร้างใหม่
Template หายอย่าย้ายหรือลบโฟลเดอร์ Template และติดตั้งรุ่นใหม่ทับโดยไม่ลบโฟลเดอร์เดิม

ถอนการติดตั้ง

ใช้ shortcut Uninstall Jangmao70 จาก Start Menu หรือโฟลเดอร์ติดตั้ง

สำรองข้อมูลก่อนยืนยัน
การถอนการติดตั้งจะลบโฟลเดอร์ของ Jangmao70 รวมถึงข้อมูลใน Data, Template และ Output ภายในโฟลเดอร์นั้น

สำหรับผู้สนใจ source code

Source ZIP มี source code, config, template และสคริปต์ build ผู้ใช้งานทั่วไปไม่ต้องดาวน์โหลดไฟล์นี้เพื่อเปิดโปรแกรม และไม่ต้องติดตั้ง npm เพื่อใช้งานตัวโปรแกรม
