แท็บสีเขียว · จัดซื้อจัดจ้างและสัญญา

เตรียมข้อมูลสำหรับชุดเอกสารจัดจ้าง

  1. ข้อมูลโรงเรียน — โรงเรียน เขตพื้นที่ ผู้อำนวยการ และเจ้าหน้าที่พัสดุ
  2. กรรมการ TOR — กรรมการ 1–3 และเลขที่คำสั่งแต่งตั้ง
  3. ข้อมูลลูกจ้าง — ข้อมูลส่วนตัว ตำแหน่ง เงินเดือน การศึกษา ที่อยู่ และบัตรประชาชน
  4. สรุปชุดเอกสาร — ตรวจและเลือกเอกสารที่ต้องการสร้าง

ตำแหน่งและเงื่อนไข เช่น มีงานสอนหรือทำงานสองโรงเรียน ใช้กำหนดเส้นทางแม่แบบเอกสาร

โฟลเดอร์ผลลัพธ์เริ่มต้นOutput/เอกสารจัดจ้าง

แท็บสีฟ้า · เบิกเงินเดือน

เตรียมเอกสารของแต่ละงวดเบิก

  • งวดและวันที่ — เดือน ปีงบประมาณ วันที่ส่งเบิก และข้อมูลใบสั่งจ้าง
  • ผู้รับจ้าง — ชื่อ ตำแหน่ง เงินเดือน และที่อยู่
  • ผู้ลงนาม — เจ้าหน้าที่และคณะกรรมการตรวจรับ
  • ชุดเอกสารเบิกเงินเดือน — เลือกรายการแล้วตรวจทานก่อนสร้าง Word

“เหมือนเดิม! แค่เปลี่ยนเดือน!” ใช้ Template เดิมและเสนอเดือนถัดไปจากงวดล่าสุดที่สร้างสำเร็จ โดยให้ยืนยันก่อนเลื่อนเดือน

ถ้ายังไม่มีประวัติสร้างสำเร็จ ต้องเลือกเดือนเอง และตรวจเดือน ปี รวมถึงวันที่ส่งเบิกทุกครั้ง

แต่ละงานบันทึก Template ของตัวเอง
การนำเข้าข้ามงานส่งต่อเฉพาะข้อมูลร่วมที่รองรับ

ข้อมูลที่ยังแยกกันงวดเบิกและเดือน รายการเอกสาร ข้อมูลเฉพาะงาน เช่น กรรมการ TOR/ตรวจรับ ตำแหน่งและเงินเดือน รวมถึง Template และ Output ของแต่ละงาน
ข้อมูลที่นำเข้าร่วมได้ชื่อโรงเรียนและเขต ผู้อำนวยการ เจ้าหน้าที่พัสดุ หัวหน้าเจ้าหน้าที่พัสดุ ข้อมูลลูกจ้าง เช่น ชื่อ เลขประชาชน วันเกิด การศึกษา ที่อยู่ และข้อมูลบัตรที่รองรับ

โหลด Template แล้วเกิดอะไรขึ้น?

กด โหลด Template เลือกชุดต้นทางและรายการที่เคยบันทึก เมื่อนำเข้าข้ามงาน ระบบจะแสดงรายงานให้ตรวจสอบก่อนยืนยัน จึงรู้ว่าข้อมูลใดจะเปลี่ยนและช่องใดต้องกรอกเพิ่ม

ส่วน บันทึก Template คือเก็บข้อมูลในฟอร์มไว้ใช้ครั้งต่อไปในเครื่อง ไม่ใช่การแก้แม่แบบ Word ต้นฉบับ

ดาวน์โหลดแล้วเจอคำเตือน?
ดูวิธีทำต่อได้ตรงนี้

สองจุดที่อาจพบระหว่างดาวน์โหลดและติดตั้ง พร้อมภาพบอกตำแหน่งที่ต้องคลิก

กรณี Chrome เตือนไฟล์มีความเสี่ยง

  1. เปิดรายการดาวน์โหลดของ Chrome แล้วคลิกรายการที่มีคำเตือนหรือเครื่องหมายลูกศร
  2. ตรวจว่าดาวน์โหลดจาก RobbyGrean/Jangmao70 และชื่อไฟล์เป็น Jangmao70-Installer.zip
  3. เมื่อตรวจสอบและเชื่อถือไฟล์แล้ว คลิก ดาวน์โหลดไฟล์ที่น่าสงสัย (บางรุ่นใช้ Keep / เก็บไว้ หรือ Keep anyway / เก็บไว้ต่อไป)
  4. ดาวน์โหลดเสร็จแล้ว แตก ZIP ก่อนเปิด Jangmao70-Setup.exe

ภาพตัวอย่างมาจาก jmoney รุ่นก่อน ชื่อไฟล์ในภาพจึงต่างกัน สำหรับโปรแกรมนี้ให้ตรวจชื่อ Jangmao70-Installer.zip

Windows protected your PC

More info → Run anyway

  1. เมื่อขึ้น Windows protected your PC ให้คลิก More info / ข้อมูลเพิ่มเติม ตามวงกลมในภาพ
  2. ตรวจชื่อแอปให้เป็น Jangmao70-Setup.exe จากไฟล์ที่ดาวน์โหลดจากเว็บไซต์นี้
  3. คลิก Run anyway / เรียกใช้ต่อไป ที่ปรากฏขึ้น แล้วทำตามหน้าต่างติดตั้ง

SmartScreen อาจเตือนเมื่อแอปยังไม่มีชื่อเสียงเพียงพอหรือไม่มีลายเซ็นที่ระบบรู้จัก ให้ทำต่อเฉพาะไฟล์ที่คุณตรวจสอบและเชื่อถือ หากไม่มีปุ่ม Run anyway เครื่องอาจถูกควบคุมด้วยนโยบายองค์กร ให้ติดต่อผู้ดูแลเครื่อง
