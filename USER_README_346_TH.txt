คู่มือใช้งาน Jangmao70
========================================

โปรแกรมนี้ใช้สำหรับกรอกข้อมูลครั้งเดียว แล้วสร้างเอกสาร Word สำหรับงานเบิกจ่ายและงานจัดซื้อจัดจ้างจากแบบฟอร์มที่เตรียมไว้


1. วิธีติดตั้ง
--------------

1) แตกไฟล์ `Jangmao70-Installer.zip` ก่อน

2) เปิดไฟล์ `Jangmao70-Setup.exe`

3) รอสักครู่ โปรแกรมจะติดตั้งให้อัตโนมัติ

4) เมื่อติดตั้งเสร็จ จะมีไอคอน `Jangmao70` บน Desktop

5) เปิดโปรแกรมจากไอคอนบน Desktop ได้เลย โปรแกรมจะเปิดที่แท็บ `จัดซื้อจัดจ้างและสัญญา`


2. โปรแกรมถูกติดตั้งไว้ที่ไหน
-----------------------------

หลังติดตั้งแล้ว โปรแกรมจะอยู่ที่:

`%LOCALAPPDATA%\Document346`

ตัวอย่าง path จริง:

`C:\Users\ชื่อผู้ใช้\AppData\Local\Document346`

ภายในโฟลเดอร์นี้จะมี:

- `Jangmao70.exe` ตัวโปรแกรม
- `Template\Payroll` และ `Template\Procurement` โฟลเดอร์เก็บแบบฟอร์ม Word
- `Output\เงินเดือน` และ `Output\เอกสารจัดจ้าง` โฟลเดอร์เก็บเอกสารที่สร้างเสร็จ
- `Data` ข้อมูล Template ที่ผู้ใช้บันทึก

หมายเหตุ:
- ผู้ใช้ไม่จำเป็นต้องเปิด path นี้เพื่อใช้งานปกติ เพราะมี shortcut บน Desktop และ Start Menu ให้แล้ว
- ถ้าต้องการแก้แบบฟอร์ม Word ให้เข้าไปที่โฟลเดอร์ `Template`
- ถ้าต้องการดูไฟล์ที่สร้างแล้ว ให้เข้าไปที่โฟลเดอร์ `Output\เงินเดือน` หรือ `Output\เอกสารจัดจ้าง`


3. วิธีใช้งาน
-------------

1) เปิดโปรแกรม `Jangmao70`

2) ใช้แท็บ `เบิกเงินเดือน` สำหรับ workflow เดิม หรือแท็บ `จัดซื้อจัดจ้างและสัญญา` สำหรับเอกสาร Procurement

3) กรอกข้อมูลร่วม เช่น โรงเรียน ผู้ลงนาม ลูกจ้าง และกรรมการ ข้อมูลจะแสดงร่วมกันทั้งสองแท็บ

4) ในแท็บเบิกเงินเดือน เลือกเดือนส่งมอบ และปี พ.ศ.
   โปรแกรมจะคำนวณงวดและปีงบประมาณให้อัตโนมัติ

5) เลือกเอกสารที่ต้องการสร้างในแท็บที่กำลังใช้งาน
   ถ้าไม่แน่ใจ ให้ติ๊กไว้ทั้งหมด

6) กรอกข้อมูลให้ครบ แล้วกดปุ่มสร้างเอกสาร

7) หากใช้ Procurement ให้เลือกตำแหน่ง ตัวเลือกงานสอน/สองโรงเรียน และ checkbox เอกสารที่ต้องการ ระบบจะเลือก route ขั้นตอน 3/6 ให้ตรงกับ template

8) เมื่อสร้างเสร็จ ไฟล์จะถูกแยกไว้ใน Output ของ workflow นั้น และชื่อซ้ำจะต่อท้าย `_2`, `_3` อัตโนมัติ


3.1 การบันทึก Template ในแท็บ Procurement
------------------------

Template ใช้เก็บข้อมูลประจำของผู้รับจ้างหรือโรงเรียน เพื่อไม่ต้องกรอกใหม่ทุกครั้ง

1) กรอกข้อมูลประจำให้ครบ เช่น ลูกจ้าง โรงเรียน ผู้ลงนาม และคณะกรรมการ

2) กดปุ่ม `บันทึก Template`

3) ตั้งชื่อและหมายเหตุให้ค้นหาได้ง่าย
   เช่น ชื่อผู้รับจ้าง หรือชื่อโรงเรียน

4) หากแก้ไขข้อมูลประจำของ Template เดิม ให้เลือกบันทึกทับ Template เดิม
   ตรวจชื่อ Template ให้ถูกก่อนยืนยัน


3.2 จัดการ Template และโหลดเข้าฟอร์ม
--------------------------------------

1) กดปุ่ม `โหลด Template`

2) เลือกรายการ Template ที่ต้องการ

3) กด `โหลดเข้าฟอร์ม` เพื่อดึงข้อมูลของรายการนั้นกลับมาแก้ไขหรือสร้างเอกสาร
   วิธีนี้ไม่เลื่อนเดือนอัตโนมัติ ให้ตรวจและเลือกเดือนส่งมอบเอง

4) หากแก้ไขข้อมูลแล้วกด `บันทึก Template` ระบบจะถามว่าจะบันทึกเป็นรายการใหม่หรือบันทึกทับรายการเดิม


3.3 เพิ่มลูกจ้างใหม่
---------------------------------

1) กดปุ่ม `เพิ่มลูกจ้างใหม่`

2) ระบบจะถามก่อนว่าต้องการบันทึกข้อมูลปัจจุบันเป็น Template หรือไม่

3) หากยืนยันบันทึก ระบบใช้ flow เดียวกับ `บันทึก Template`; หากไม่บันทึก ระบบจะล้าง record ปัจจุบัน

4) ถ้ายกเลิกหรือบันทึกไม่สำเร็จ ระบบจะรักษาข้อมูลเดิมไว้

5) หลังเริ่ม record ใหม่ ฟอร์มจะว่างและตั้งเขตพื้นที่เริ่มต้นตามค่าที่กำหนด


4. ไฟล์ที่สร้างเสร็จอยู่ที่ไหน
------------------------------

โดยปกติไฟล์ที่สร้างเสร็จจะอยู่ที่:

`%LOCALAPPDATA%\Document346\Output\เงินเดือน` หรือ `%LOCALAPPDATA%\Document346\Output\เอกสารจัดจ้าง`

ตัวอย่าง path จริง:

`C:\Users\ชื่อผู้ใช้\AppData\Local\Document346\Output`

หรือดูจากช่อง `Output` ในหน้าโปรแกรมก็ได้


5. ถ้าต้องการแก้ Template
--------------------------

ให้เข้าไปที่โฟลเดอร์:

`%LOCALAPPDATA%\Document346\Template`

แล้วแก้ไฟล์ Word `.docx` ได้เลย

ข้อแนะนำ:
- แก้เฉพาะข้อความหรือรูปแบบที่ต้องการ
- อย่าลบ tag ในวงเล็บปีกกา เช่น `{ชื่อโรงเรียน}` ถ้ายังต้องการให้โปรแกรมแทนค่าอัตโนมัติ
- ถ้าแก้ template แล้ว ควรปิดไฟล์ Word ก่อนกลับมาสั่งสร้างเอกสาร


6. ข้อควรระวัง
---------------

1) ก่อนกดสร้างเอกสาร ควรปิดไฟล์ Word ที่เคยเปิดค้างไว้ก่อน
   ถ้าเปิดไฟล์เดิมค้างไว้ โปรแกรมอาจเขียนทับไฟล์นั้นไม่ได้

2) ตรวจเดือนส่งมอบและปี พ.ศ. ให้ถูกต้องก่อนสร้าง

3) ถ้าโปรแกรมแจ้งว่าไม่พบ Template
   ให้ตรวจว่าโฟลเดอร์ `Template` ยังอยู่ในโฟลเดอร์ติดตั้งหรือไม่

4) ถ้าโปรแกรมเปิดได้ แต่เอกสารสร้างไม่ออก
   ให้ตรวจว่าโฟลเดอร์ `output` ยังอยู่หรือไม่


7. การถอนการติดตั้ง
-------------------

วิธีถอนการติดตั้ง:

1) เปิด Start Menu

2) ค้นหา `Jangmao70`

3) เลือก `Uninstall Jangmao70`


8. หากใช้งานไม่ได้
------------------

ให้แจ้งผู้ดูแลพร้อมข้อมูลเหล่านี้:

1) โปรแกรมแจ้งว่าอะไร

2) ทำถึงขั้นตอนไหนแล้วเกิดปัญหา

3) ไฟล์ Word ที่สร้างออกมาผิดตรงไหน

4) ถ้ามีภาพหน้าจอ ให้ส่งภาพหน้าจอมาด้วย
